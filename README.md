# ATM Banking System

A console-based ATM Banking System developed using Java.

## Features

- PIN Authentication with 3 Attempts
- Check Account Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Session Summary

## Technologies Used

- Java
- Arrays
- Loops
- Conditional Statements
- Scanner Class

## How to Run

1. Compile the program:
   javac ATMSystem.java

2. Run the program:
   java ATMSystem
